Introduction to AI & Python

About This Project

This repository contains my learning notes and beginner-friendly Python programs completed as part of Module 01: Introduction to AI & Python.

The purpose of this project is to understand the fundamentals of Artificial Intelligence, Machine Learning, and Python programming.

Learning Objectives

- Learn the basics of Artificial Intelligence and Machine Learning.
- Understand the differences between AI, ML, and Deep Learning.
- Explore real-world applications of AI.
- Practise Python programming concepts such as variables, loops, functions, and lists.
- Develop beginner-friendly Python programs.

Programs Included

- "hello.py" – Basic output, variables, and user input.
- "even_odd.py" – Check whether a number is even or odd.
- "multiplication_table.py" – Generate a multiplication table.
- "calculator.py" – Perform basic arithmetic operations.
- "functions_and_lists.py" – Practise functions and lists.

Technologies Used

- Python 3
- GitHub

How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run a program using:

python hello.py

On Linux, you may need to use "python3" instead.

Learning Outcome

Through this module, I gained an understanding of AI and ML concepts and practised writing simple Python programs using fundamental programming concepts.
